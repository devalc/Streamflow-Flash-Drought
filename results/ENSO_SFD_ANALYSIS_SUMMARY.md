# ENSO-Streamflow Flash Drought Analysis Summary

## Research Question
How do streamflow flash droughts (SFDs) vary during different seasons in El Niño and La Niña years, and what is the frequency of SFDs in the absence/presence of dams across all ecoregions?

## Dataset Overview
- **Total SFD Events**: 89,550
- **Date Range**: 1981-10-31 to 2024-12-16
- **Unique Catchments**: 2,761
- **Ecoregions**: 9

## ENSO Phase Distribution
- **El_Nino**: 48,920 events (54.6%)
- **La_Nina**: 31,602 events (35.3%)
- **Neutral**: 9,028 events (10.1%)

## Key Findings

### Seasonal Patterns by ENSO Phase
**El_Nino:**
- Spring: 14,860 events
- Summer: 12,776 events
- Fall: 11,935 events
- Winter: 9,349 events

**La_Nina:**
- Spring: 7,471 events
- Summer: 8,077 events
- Fall: 8,413 events
- Winter: 7,641 events

**Neutral:**
- Spring: 2,955 events
- Summer: 2,544 events
- Fall: 2,133 events
- Winter: 1,396 events

### Dam Influence Across ENSO Phases
**El_Nino:**
- Dam Present: 20,437 events
- Dam Absent: 20,691 events

**La_Nina:**
- Dam Present: 13,217 events
- Dam Absent: 13,266 events

**Neutral:**
- Dam Present: 4,000 events
- Dam Absent: 3,672 events

## Files Generated
- `enso_sfd_analysis.png` - Comprehensive visualizations
- `enso_sfd_frequency_*.csv` - Detailed frequency analysis by dam type
- `enso_sfd_summary_*.csv` - Summary statistics by ENSO phase and season
- `ecoregion_enso_patterns_*.csv` - Ecoregion-specific ENSO responses
- `ENSO_SFD_ANALYSIS_SUMMARY.md` - This summary report

## Interpretation
This analysis reveals how climate oscillations (ENSO) interact with dam infrastructure to influence streamflow flash drought patterns across different seasons and ecoregions. The results provide insights for seasonal drought forecasting and water management strategies during El Niño and La Niña events.
